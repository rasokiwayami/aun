# ひとつずつ · hitotsuzutsu

一度に一つの質問から、自分の価値観・好み・判断の条件を言葉にしていく、ローカル実行の会話プロトタイプです。

目指しているのは、本人が確かめて直せる個人コンテキストを作り、普段のAIへの説明し直しや修正を減らすことです。現在は**会話・原文保存・根拠付きの未確認整理**までを実装しています。本人確認、訂正の伝播、用途別の情報抽出、ほかのAIへの継続的な受け渡しは、これから設計する部分です。

## 現在できること

- 200問の暫定汎用質問集と各質問の目的を参照し、短い問いを一つ返す
- テキスト入力、Mac内の音声認識、読み上げによる交互会話
- 回答をモデル呼び出し前に保存し、失敗時にも原文を保持する
- 原文中の引用を根拠に、部分回答・回答済み・不明・保留・回答拒否を未確認の整理として記録する
- 記録全体をJSONで書き出す

200問を完答する必要はありません。質問集は公開設計用の暫定版であり、今後、優先順位をつけた約300問規模の汎用設計へ見直す予定です。項目数よりも、役に立つ判断が得られるかを重視します。

## ローカルで動かす

現在の音声・認証情報保護はmacOS専用です。Node.js 26以上、Git、Swiftコンパイラを含むXcode Command Line Toolsが必要です。

```sh
npm ci
```

認証アダプターはOpenAIのDevKitを任意で取得します。このDevKitには本体のMITとは別の**非商用ライセンス**が適用されます。[条件](LICENSES/README.md)を読み、利用条件に合う場合のみ実行してください。

```sh
npm run setup:siwc -- --accept-noncommercial
npm run build
npm test
npm run check:public
npm start
```

ブラウザで `http://127.0.0.1:43127/` を開き、ChatGPTにサインインして利用枠の使用を許可します。対象アカウント・モデル・利用枠の可否はサービス側の条件によります。サインインは、ChatGPTの過去の会話やメモリの取得ではありません。

「話しはじめる」から始めます。初回にマイクと音声認識の許可が必要です。「少し待って」で中断、「今日はここまで」で終了できます。音声の往復は利用環境での確認が必要です。

## 保存と送信

記録は `.local/conversations/` に保存します。原文とAIの整理案は、ファイル権限で保護された**平文JSON**です。認証情報は別にKeychainの鍵で暗号化します。音声はMac内で文字に変換し、録音ファイルは保存しません。質問設計、回答履歴、整理案は、返答を生成する際に接続したChatGPTへ送信します。現状は用途別に必要最小限だけ送る仕組みではありません。

このリポジトリには利用者のプロフィール、実際の回答、認証情報は含めません。学習用データセットへの提供や、ほかのAIへの自動同期も行いません。個人情報を大量に預けられる完成品としては、まだ扱わないでください。
