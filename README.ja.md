# AUN · 阿吽

### あなたのAIに、阿吽の呼吸を。

**AIに、何度も自己紹介する人生を終わらせよう。**

あなたの好み。譲れないこと。判断の理由。もう何度も説明した、あの前提。

わかってもらうために、毎回完璧なプロンプトを書く必要があるだろうか。

AUNは、あなたを理解するための文脈を鍛える、ローカルアプリです。話す。AIが受け取った意味を確かめる。必要な記憶を、次の会話へ持っていく。

**あなたの物語を、あなたのルールで、次のAIへ。**

## 「わかってくれている」を、会話の初期値に。

言葉を尽くさなくても、意図が伝わる。全部を説明しなくても、呼吸が合う。

目指すのは、AIとの**阿吽の呼吸**。説明し終える前に、あなたの考えの輪郭が伝わる関係。毎回初対面の相手に事情を説明する感覚から、気心の知れた相手と話の続きをする感覚へ。

「そう、それが言いたかった。」を、当たり前にしたい。

そのために今つくっているのは、好み、優先順位、境界線、答えが変わる条件を残す仕組みです。何を自分のこととして残し、直し、どこへ持ち出すかは、あなたが決めます。

## 次のAIに、あなたの続きを渡す。

*使い方を示す架空の例です。実際の会話や生成結果ではありません。*

> **あなた：**「週末の旅行は、繁華街の近くより静かな宿がいい。でも友達と行くなら別かな。」
>
> **確認するメモの例：** 一人で行く週末旅行では静かな宿を好む。友人との旅行では別途確認する。
>
> **使う：** 確認したメモを旅行用の文脈に含め、相談したいAIへ貼り付ける。

一度話したことが、次に使える前提になる。例外も一緒に残す。解釈が合っているかは、自分で確かめる。

### 話題は、向こうから。

保管庫を開くと、具体的な最初の質問が表示されます。任意のChatGPT接続と送信をオンにすると、回答に合わせた質問が続きます。300問の質問集は、話し始めるための入口。全部に答える必要はありません。飛ばす。今日はやめる。同じ質問から、また始める。

### 「あなたはこういう人」を、AIに決めさせない。

話した言葉とAIの解釈を分けて保存します。整理案を確かめ、保留し、今回だけ採用することもできます。保存したメモは編集でき、元の発言まで戻って確認できます。原文を訂正すると、それに依存するメモは失効します。昔の解釈に、今の自分を代弁させないためです。

### AIを変えても、自分の説明は持っていける。

用途を選び、含めるメモを確認して、MarkdownやJSONへ書き出します。相談に必要な前提を次のAIに渡せば、自己紹介を一から組み立て直す手間を減らせます。受け渡しは手動です。ChatGPT内のメモリへ自動で書き込む機能ではありません。

## 始める

**初期プロトタイプです。** 現在の画面は日本語で、旧名称の**ひとつずつ**を表示します。

ローカルの基本機能には **Node.js 26以上**が必要です。記録・確認・編集・書き出しには、ChatGPT接続やネイティブビルドは不要です。

```sh
git clone https://github.com/rasokiwayami/aun.git
cd aun
npm ci
npm start
```

[ローカル画面](http://127.0.0.1:43127/)を開き、保管庫のパスフレーズを設定します。復旧コードを作る場合は別の安全な場所に保管してください。パスフレーズと復旧材料を両方失うと復旧できません。

1. 最初の質問に答える。送信がオフの間は端末内に記録し、**別の問いへ**で進みます。
2. 任意のAI接続を使う場合は、**整理案**で解釈を確認する。メモを自分で直接作ることもできます。
3. **使えるメモ → 用途に合わせて使う**で、出力内容を確認して書き出す。
4. **今日はここまで**で区切る。保存した回答と質問位置は残ります。書きかけは、保存を選んだ場合だけ24時間残します。

### 任意のChatGPT接続とMac音声

認証用DevKitには、別の**非商用ライセンス**が適用されます。取得前に[依存関係とサービスの利用条件](LICENSES/README.md)を確認してください。本体のMITライセンスで、この条件が変わることはありません。

macOSとXcode Command Line Toolsがある環境で実行します。

```sh
npm run setup:siwc -- --accept-noncommercial
npm run build
```

画面から接続し、回答に応じた質問や整理案を使うときに送信をオンにします。利用可否はアカウントの対象条件やサービスの利用枠に依存します。既存のChatGPTの会話やメモリは取り込みません。

音声入力は、Mac内で日本語を文字起こしします。マイクは自分で開始し、認識途中の文は下書きに残ります。実機でマイクの起動と停止を確認しています。実発話の認識精度と、音声での対話の往復は未検証です。

## 記憶には、消す自由も、書き直す自由も。

保管庫は端末内に暗号化して保存します。クラウド推論は任意で、送信には同意が必要です。オンにすると、今回の回答と、選ばれた許可済みの文脈をプロバイダーへ送ります。AIとの対話まで完全オフラインで動くわけではありません。

メモには用途、条件、期限、AI利用と対外開示の許可を設定できます。訂正や削除もできます。ただし、書き出したコピーやサービスへ送信済みの内容をAUNから回収することはできません。独立したバックアップは別のコピーとして残ります。

暗号化、復旧、削除、端末自体が侵害された場合の限界は、[データ保護の説明](SECURITY.md)を参照してください。

## 仕組み

```text
あなたの言葉 → 原文の記録 → AIの整理案 → あなたの確認
                                              ↓
                                    用途・条件・期限・許可
                                              ↓
                                    Markdown / JSONで出力
```

設計の原則は、**モデルの推測を、そのままあなたの定義にしないこと。**

原文の根拠、解釈、本人の確認、行動の権限を分けます。保存の中核は暗号化したSQLite。対話は任意のプロバイダー接続で動きます。書き出す文脈は情報資料であり、あなたに代わって行動する許可ではありません。
